# GAME SYSTEM SPEC

## 1. 목적

게임은 자세 관리와 분리된 장식이 아닙니다. 자세 회복·세션 완주·짧은 움직임이 실제 게임 결과로 변환됩니다.

## 2. 핵심 루프

```text
세션 시작
→ 자세 변화
→ 회복 기회
→ 회복 성공
→ 특수 공격
→ 세션 완주
→ 기본 공격
→ 스트레칭
→ 방어막 회복
→ XP·포인트·출석
→ 성장·상점
→ 다음 세션
```

## 3. 행동 매핑

| 현실 행동 | 게임 결과 |
|---|---|
| 세션 완주 | 기본 공격 |
| 자세 회복 | 특수 공격 |
| 가까운 시간의 2인 회복 | 기린 싱크 |
| 스트레칭 완료 | 방어막 회복 |
| 두 사용자 모두 완주 | 최종 필살기 |
| 주간 출석 | 아이템·포인트 |
| 목표 완료 자기보고 | 보너스 상자 |
| away·unstable | 판정 정지 |

## 4. 캐릭터 성장

| 단계 | 이름 | 누적 XP 초기값 | 시각 차이 |
|---:|---|---:|---|
| 1 | 뽀각 거북 | 0 | 목 완전 숨김, 큰 등껍질 |
| 2 | 꿈틀 거북 | 250 | 머리와 짧은 목 등장 |
| 3 | 빼꼼 거부기린 | 600 | 짧은 기린 목·작은 뿔·큰 등껍질 |
| 4 | 반듯 거부기린 | 1000 | 중간 목·세운 몸통·작은 등껍질 |
| 5 | 쭉쭉 기린 | 1500 | 완전한 기린 체형 |
| 6 | 우뚝 기린 | 2200 | 가장 긴 목·과잠·백팩·당당한 표정 |

초기값은 게임 밸런스 테스트용입니다.

## 5. 세션 상태와 성장 분리

사용자가 Lv.4라면 세션 중에도 Lv.4 캐릭터가 자세에 따라 움직입니다.

```text
idle
→ warning
→ slouch
→ recover
→ attack
→ celebrate
```

자세가 흐트러져도 이전 레벨로 퇴화하지 않습니다.

## 6. 기본 보스

### 마감괴수 D-DAY

- 과제지·보고서로 만든 몸
- 디지털 마감 시계 얼굴
- `D-DAY` 도장
- HP 30% 이하에서 `23:59`
- 처치 시 `제출 완료`

### 체력 상태

| HP | 연출 |
|---|---|
| 100~61% | 기본 |
| 60~31% | 화남·포스트잇·배경 변화 |
| 30~1% | 23:59 폭주 |
| 0% | 제출 완료 |

## 7. 초기 수치

### 데미지

| 행동 | 값 |
|---|---:|
| 세션 완주 | 100 |
| 회복 성공 | 40 |
| 기린 싱크 보너스 | 60 |
| 두 사용자 모두 완주 | 150 |
| 목표 완료 | 30 |

### XP·포인트

| 행동 | XP | 잎사귀 포인트 |
|---|---:|---:|
| 25분 완료 | 100 | 100 |
| 회복 성공 | 30 | 10 |
| 스트레칭 | 20 | 20 |
| 2인 방 완료 | 30 | 30 |
| 목표 완료 | 20 | 20 |

## 8. 회복 콤보

- 연속 회복 성공 시 +1
- 회복 기회 실패 시 현재 세션 콤보만 0
- away·unstable은 실패가 아님
- 이미 획득한 XP와 성장 유지

## 9. 기린 싱크

조건:

- 서로 다른 두 사용자의 회복 이벤트가 10초 안에 발생
- 이벤트 ID 중복 금지
- 동일 이벤트 재사용 금지

표시:

> 두 사람의 회복 에너지가 연결됐어요. 기린 싱크!

## 10. 출석

- 10분 이상 진행 또는 정상 완료
- 주간 목표 3·5회 선택
- 휴식일 표시
- 스트릭 끊김 처벌 없음

## 11. 상점 잠금 해제

첫 정상 세션 완료 후 상점과 첫 100포인트를 노출합니다.

## 12. 악용 방지

- 흐트러짐 자체 보상 없음
- 한 bad 구간 보상 1회
- 20초 냉각
- XP 회복 보상 세션당 최대 5회
- 비정상적으로 짧은 반복 이벤트 필터
- 세션 완주 기본 보상
- 친구 방 이벤트 중복 제거
- 장기 XP 차감 없음

## 13. 피해야 할 규칙

- 자세가 나쁜 친구 공격
- 자세 점수 순위
- 실패 시 캐릭터 파괴
- 스트레칭 건너뛰기 벌점
- 공부 중 반복 조작
- 현금 상금
- 과도한 사운드·화면 흔들림
