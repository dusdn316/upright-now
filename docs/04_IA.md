## 3. 내비게이션

5. 상점

- PIP 또는 미니 위젯

## 4. 점진적 노출

| 시점 | 기능 |
|---|---|
| 첫 방문 | 설명·닉네임·프로필·캘리브레이션 |
| 기준 등록 후 | 세션 설정·집중 시작 |
| 첫 세션 완료 | 기록·성장·출석 |
| 포인트 획득 | 상점 |
| 친구 방 선택 | 방 생성·입장 |
| 반복 사용 후 | 흐트러짐 등록·사용자 정의 모드 |

## 5. 핵심 데이터 개체

| 개체 | 설명 |
|---|---|
| UserPreference | 닉네임·접근성·소리 |
| LearningProfile | 장소 기준 + 피드백 설정 |
| CalibrationProfile | 개인 기준 요약 |
| Session | 세션 설정과 상태 |
| SessionSummary | 집계 결과 |
| CharacterProfile | 단계·XP·포인트·장착 |
| AttendanceRecord | 날짜별 출석 |
| StoreItem | 과잠·백팩 |
| Room | 2인 방 설정 |
| RoomMember | 닉네임·준비·진행 상태 |
| RoomEvent | 회복·스트레칭·완료·응원 |
| StretchRoutine | 모션·시간·모드 가중치 |
