# STORE & CUSTOMIZATION SPEC

## 1. 목적

자세 관리의 핵심 경험을 완료한 뒤 사용자가 캐릭터에 애착을 갖고 다시 세션을 시작하도록 하는 보조 시스템입니다.

## 2. 재화

### XP

- 캐릭터 성장 전용
- 소비하지 않음

### 잎사귀 포인트

- 과잠·백팩 구매
- 구매 시 차감
- 실제 화폐와 교환 불가

## 3. 잠금 해제

첫 정상 세션 완료 후 상점을 노출합니다.

```text
세션 완료
→ 100 포인트 획득
→ 상점 잠금 해제
→ 첫 과잠·백팩 보기
```

## 4. MVP 아이템

### 대학 컬러 과잠

- 네이비
- 버건디
- 포레스트 그린
- 코랄

사용자 선택:

- 색상
- 영문 이니셜 1~2자
- 일반 학과 패치

공식 학교 로고·마스코트는 사용하지 않습니다.

### 캠퍼스 백팩

- 새내기 백팩
- 도서관 백팩
- 팀플 백팩

## 5. 데이터 모델

```ts
interface StoreItem {
  id: string;
  type: "jacket" | "backpack";
  name: string;
  description: string;
  price: number;
  assetKey: string;
  availableStages: number[];
  defaultUnlocked?: boolean;
}

interface InventoryItem {
  itemId: string;
  purchasedAt: number;
}

interface EquippedItems {
  jacketId?: string;
  backpackId?: string;
}
```

## 6. 초기 가격

| 아이템 | 포인트 |
|---|---:|
| 네이비 과잠 | 120 |
| 버건디 과잠 | 150 |
| 포레스트 과잠 | 150 |
| 코랄 과잠 | 180 |
| 새내기 백팩 | 100 |
| 도서관 백팩 | 160 |
| 팀플 백팩 | 180 |

테스트용 초기값입니다.

## 7. 구매 흐름

```text
아이템 선택
→ 현재 단계 미리보기
→ 포인트 확인
→ 구매
→ 인벤토리 저장
→ 장착 여부 선택
```

포인트 부족:

> 잎사귀 포인트가 조금 더 필요해요. 다음 세션을 완료해 볼까요?

## 8. 장착

- 과잠 1개
- 백팩 1개
- 장착·해제 가능
- 현재 브라우저 로컬 저장
- 성장 단계 변경 후 동일 아이템을 새 단계에 매핑

## 9. 시각 구현

### 권장

기본 캐릭터 + 투명 레이어

### 폴백

각 단계와 아이템 조합의 완성 렌더 이미지

MVP에서는 조합 수를 제한해 제작량을 관리합니다.

## 10. 금지

- 랜덤 가챠
- 결제
- 실시간 AI 아이템 생성
- 실제 학교 상표 무단 사용
- 자세가 나빠졌다는 이유로 아이템 회수
- 포인트를 건강 점수처럼 표현

## 11. QA

- 구매 후 중복 차감 없음
- 새로고침 후 인벤토리 유지
- 성장 단계 변경 후 장착 유지
- 포인트 부족 처리
- 데이터 초기화 시 인벤토리 삭제
- 에셋 누락 시 기본 캐릭터 유지
