# ACCEPTANCE TESTS

## 1. Definition of Done

### 이해

- [ ] 첫 사용자가 10초 안에 서비스 목적을 설명할 수 있음
- [ ] 자세 관리가 중심이고 게임이 보조임을 이해함
- [ ] 영상 미저장·미전송을 확인할 수 있음

### 첫 사용

- [ ] 닉네임 저장
- [ ] 학습 프로필 선택
- [ ] 권한 전 카메라 안내
- [ ] 5초 캘리브레이션
- [ ] 1분 안에 세션 시작

### 자세 엔진

- [ ] good·warning·bad·away·unstable
- [ ] bad 5초 미만에 회복 기회 없음
- [ ] good 5초 유지 후 성공
- [ ] 같은 구간 보상 1회
- [ ] 20초 냉각
- [ ] 세션당 XP 보상 상한
- [ ] away·unstable 실패 처리 안 함

### 세션

- [ ] 기본 25분
- [ ] 15·50분 선택
- [ ] 3분 데모
- [ ] 2분 리셋
- [ ] 수동 종료
- [ ] 자리 비움 처리

### 캐릭터·게임

- [ ] 6단계 성장
- [ ] 현재 자세와 성장 단계 분리
- [ ] 회복 → 공격
- [ ] 완주 → 기본 공격
- [ ] XP·포인트
- [ ] 보스 HP 중복 감소 없음

### 스트레칭

- [ ] 6종
- [ ] 모드별 가중 랜덤
- [ ] 직전 동작 제외
- [ ] 일시정지
- [ ] 다른 동작
- [ ] 건너뛰기
- [ ] 안전 문구
- [ ] 건너뛰기 벌점 없음

### 결과·기록

- [ ] 세션 시간과 감지 가능 시간 분리
- [ ] 자리 비움 표시
- [ ] 회복 성공·기회
- [ ] 자세 점수 없음
- [ ] 출석 갱신
- [ ] 목표 진행도 자기보고

### 상점

- [ ] 첫 세션 후 잠금 해제
- [ ] 과잠·백팩 표시
- [ ] 포인트 차감
- [ ] 중복 구매 방지
- [ ] 장착·해제
- [ ] 새로고침 유지

### 2인 방

- [ ] 익명 인증
- [ ] 코드·링크 입장
- [ ] 최대 2명
- [ ] 두 사람 준비 전 시작 불가
- [ ] 공동 보스
- [ ] 회복 이벤트
- [ ] 기린 싱크
- [ ] 연결 끊김 후 개인 세션 유지
- [ ] 자세 좌표 전송 없음

### 개인정보

- [ ] 네트워크 탭에 영상·프레임 없음
- [ ] IndexedDB에 원본 랜드마크 없음
- [ ] 친구에게 bad 상태 없음
- [ ] RLS 활성화
- [ ] 전체 데이터 삭제

### 접근성

- [ ] 키보드 탐색
- [ ] 포커스 링
- [ ] 소리 없이 사용
- [ ] 감소된 모션
- [ ] 색 외 텍스트 상태
- [ ] 200% 확대

### 배포

- [ ] lint
- [ ] typecheck
- [ ] unit test
- [ ] E2E smoke test
- [ ] build
- [ ] Vercel Preview
- [ ] Vercel Production

## 2. 주요 시나리오

### AT-01 첫 사용자

1. `/` 진입
2. 닉네임
3. 도서관 프로필
4. 카메라 허용
5. 기준 등록
6. 3분 데모
7. 결과

예상: 영상 저장 없이 세션 요약과 성장 생성.

### AT-02 권한 거부

예상: 막힌 화면이 아니라 재요청·설정·데모 경로.

### AT-03 순간 움직임

bad 4초.

예상: 회복 기회·공격 없음.

### AT-04 회복 성공

bad 5초 → good 5초.

예상: 한 번의 공격·XP·포인트.

### AT-05 중복 보상

같은 bad 구간에서 상태 반복.

예상: 보상 1회.

### AT-06 away

30초 인물 미감지 후 복귀.

예상: 타이머 유지, 자세 보상 정지, 벌점 없음.

### AT-07 unstable

품질 낮음 주입.

예상: 복구 안내, 결과 신뢰도 분리.

### AT-08 캐릭터 에셋 실패

예상: 기본 SVG·텍스트, 세션 계속.

### AT-09 스트레칭

도서관 모드 3회 추천.

예상: 조용한 동작 우선, 직전 동작 반복 없음.

### AT-10 상점

100포인트로 백팩 구매·장착·새로고침.

예상: 포인트·장착 유지.

### AT-11 2인 방

브라우저 A·B 입장, 준비, 시작, A 회복.

예상: 공동 HP 감소, 카메라 데이터 없음.

### AT-12 기린 싱크

A와 B가 10초 안에 회복.

예상: 합동 공격 1회.

### AT-13 연결 끊김

B 네트워크 차단.

예상: A 개인 세션 계속, 재연결 안내.

### AT-14 RLS

방 멤버가 아닌 사용자로 방 조회·변경.

예상: 차단.

### AT-15 데이터 초기화

예상: 닉네임·기준·기록·성장·상점 삭제.
