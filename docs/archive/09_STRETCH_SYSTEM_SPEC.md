# STRETCH SYSTEM SPEC

## 1. 목적

스트레칭은 자세 분석 결과로 특정 신체 문제를 처방하는 기능이 아니라, 오래 앉아 있던 흐름을 짧게 리셋하는 선택 기능입니다.

## 2. 기본 동작 6종

| ID | 동작 | 기본 시간 | 특징 |
|---|---|---:|---|
| shoulder-roll | 어깨 천천히 돌리기 | 30초 | 모든 환경 |
| scapular-squeeze | 날개뼈 가볍게 모으기 | 30초 | 앉아서 가능 |
| wrist-forearm | 손목·전완 움직이기 | 30초 | 키보드 사용 후 |
| seated-twist | 앉은 상태 등 회전 | 30~45초 | 조용하게 가능 |
| neck-turn | 목 좌우 천천히 움직이기 | 30초 | 큰 원형 회전 금지 |
| calf-raise | 일어서기·종아리 올리기 | 45초 | 공간이 있을 때 |

## 3. 모드별 가중치

값은 상대 확률입니다.

| 동작 | 도서관 | 내 공간 | 팀플 |
|---|---:|---:|---:|
| 어깨 돌리기 | 5 | 4 | 5 |
| 날개뼈 모으기 | 5 | 4 | 5 |
| 손목·전완 | 5 | 3 | 3 |
| 앉은 등 회전 | 4 | 4 | 3 |
| 목 좌우 | 3 | 5 | 3 |
| 종아리 올리기 | 1 | 5 | 5 |

## 4. 선택 알고리즘

```text
현재 학습 프로필
→ 활성 동작 목록
→ 직전 동작 제외
→ 사용자가 건너뛴 동작의 즉시 재추천 방지
→ 가중 랜덤
→ 하나 추천
```

세션마다 완전 랜덤이 아니라 반복을 줄이는 seeded shuffle 또는 최근 3개 이력도 사용할 수 있습니다.

### 세션 종료

- 2분 리셋 자동 시작
- 예약된 동작 또는 모드별 랜덤
- 동작 변경 가능
- 건너뛰기 가능

## 6. 화면 요소

- 동작명
- WebM·GIF·SVG 모션
- 한 문장 설명
- 타이머
- 일시정지
- 다른 동작
- 건너뛰기
- 안전 문구
- 완료 보상

## 7. 게임 연결

| 행동 | 결과 |
|---|---|
| 완료 | 방어막 회복·XP·포인트 |
| 건너뛰기 | 불이익 없음 |
| 친구 방 동시 완료 | 팀 방어막 보너스 · P1 |

## 8. 안전 문구

> 통증이나 어지럼증이 느껴지면 바로 멈춰 주세요. 이 안내는 의료 진단이나 치료를 대신하지 않습니다.

## 9. 금지

- 특정 근육 문제 감지 주장
- 통증 치료·예방 주장
- 카메라로 수행 여부 강제 판정
- 목을 빠르게 원형으로 돌리는 기본 동작
- 스트레칭 거부 벌점

## 10. 에셋 규격

- 30fps 이하 WebM 권장
- 3~6초 루프
- 720×720 또는 960×540
- 투명 배경 또는 아이보리 배경
- 감소된 모션용 정지 WebP
- 사람 실루엣 + 캐릭터 보조 또는 캐릭터 단독

건강 상태·통증 부위는 저장하지 않습니다.
