# 캠퍼스 테마 · 캠퍼스 영토전 (프로토타입)

> Notion 에 그대로 붙여넣을 수 있는 섹션입니다. 아래부터 전부 복사하세요.

---

## 한 줄 요약

학교를 직접 고르면 앱 색과 배경이 바뀌고, 집중 세션의 **성공 행동**이
가상 캠퍼스 지도의 영토로 쌓이는 **비공식 게임형 프로토타입**입니다.
자세 판정·XP·보상·괴물 HP·친구 방 성능은 하나도 바뀌지 않습니다.

---

## 반드시 함께 읽어야 하는 전제

- 대학 인증(재학 확인)이 **없습니다.**
- 화면 문구: **"사용자가 직접 선택한 비공식 캠퍼스 테마입니다."**
- 학교 **공식 로고·마스코트를 사용하지 않습니다.** 학교 이름 텍스트 + 일반 패턴만 씁니다.
- 색은 **프로토타입 컬러 프리셋**입니다. 공식 색상이 아니며 그렇게 표시하지 않습니다.
- 순위는 **공식 순위가 아닙니다.**
- 기본값은 **꺼져 있습니다.** Production 에는 노출되지 않습니다.
- Production Supabase 에는 **아무 SQL 도 실행하지 않았습니다.** migration 파일만 작성했습니다.

## 1. 캠퍼스 테마

### 학교 (1차)

서울대 · 연세대 · 고려대 · 서강대 · 성균관대 · 한양대 · 중앙대 · 경희대 ·
한국외대 · 서울시립대 · **기타 / 직접 설정**

`기타` 를 고르면 8색 팔레트 또는 HEX 직접 입력으로 색을 정합니다.
색만 바꾸는 것은 학교 변경으로 세지 않습니다.

### 학교 선택이 바꾸는 것

- 메인 포인트 색
- 사이드바 선택 색
- 프로필 학교 배지
- 친구 방 상단 배너
- 결과 공유 카드 테두리
- 과잠 기본 색상
- 캠퍼스 백팩 테마
- 도서관 배경 패턴
- 시험기간 배경 (시즌 종료 3일 이내)

### 바뀌지 않는 것

자세 판정 · XP · 보상량 · 괴물 HP · 친구 방 성능 ·
자세 상태 색(편안함/변화 감지/회복 기회)

## 2. 캠퍼스 영토전

### 지도

- 자체 제작 **12 × 8 = 96 타일** 가상 캠퍼스
- 실제 서울 지도나 특정 학교 부지를 복제하지 않았습니다
- 구역: 강의동(위) · 도서관 / 광장 / 카페(가운데) · 잔디밭(아래)
- 표시: 현재 점령 학교 · 점령 진행도 · 최근 영토 변화 · 시즌 남은 시간 · 내 기여도

### 시즌

- 14일 고정
- 종료 시 최종 지도를 기록에 보관하고, 새 시즌 지도는 전부 중립으로 초기화

---

## 3. 기여도

**자세 점수는 쓰지 않습니다.** "성공했다는 사실"만 씁니다.

| 이벤트 | 점수 |
| --- | --- |
| 정상 완료 세션 | +100 |
| 자세 회복 성공 | +20 |
| 친구 세션 완주 | +50 (완료 100과 별개 → 친구 방 완주 시 합계 150) |
| 스트레칭 완주 | +20 |

**중도 종료 · 데모 · QA 는 기여도가 없습니다.**

### 악용 방지

- `eventId` 중복 차단 (로컬 원장 + 저장소 + DB PK 3중)
- `sessionId` 중복 차단 (완주 계열은 세션당 1회)
- 하루 최대 **600점** (넘으면 남은 만큼만 인정)
- 회복 기여 **세션당 5회**, **최소 20초 간격**
- 동일 익명 사용자 **1분에 12건**
- 학교를 바꿔도 **이전 학교 기여도는 옮겨지지 않습니다**
- 로컬 저장소를 지워도 저장소가 `eventId` 를 기억해 이중 계산이 안 됩니다

### 학교 규모 보정

```
규모 보정 점수 = 총 기여도 ÷ √(참여자 수)
```

총 기여도와 보정 점수를 **함께** 보여 줍니다.
예) A학교 10,000점 / 400명 → 500점 · B학교 3,000점 / 20명 → 671점 → **B가 앞섬**
→ 인원이 많은 학교가 총량만으로 이기지 않습니다. (공식 순위가 아닙니다)

## 4. 영토 점령 규칙

각 타일: 점령 학교 · 도전 학교 · 방어 점수 · 공격 점수 · 갱신 시각 · 시즌

1. 내 학교가 점령 중이면 → **방어 점수 증가**
2. 남의 타일이면 → **공격 점수 증가**
3. 다른 학교가 이미 공격 중이면 → 그 공격 점수를 깎고, 0 이하가 되면 내가 공격자
4. **공격 점수 > 방어 점수 → 점령.** 넘친 점수는 새 점령 학교의 방어 점수로 이어짐
5. **점령 직전 80% 이상 → 지도에 "경합" 표시** (색 + 점선 + 진행 바 + 스크린리더 안내)
6. 점령 순간 **색상 변화 애니메이션** (700ms, 1회)
7. **열린 두 브라우저 탭에 즉시 반영** (mock 실시간)

## 6. 학교 변경 제한

- **시즌 중 1회** 그리고 **마지막 변경으로부터 7일** 뒤에 변경 가능
  (둘 다 만족해야 합니다 → 다음 가능 시점 = 시즌 종료와 7일 후 중 늦은 쪽)
- 첫 선택은 변경으로 세지 않습니다
- 잠긴 동안 다른 학교 선택이 비활성화되고 이유·다음 가능 시각을 보여 줍니다
- 학교를 바꿔도 이전 학교 기여도는 그 학교에 남습니다

## 7. 기능 플래그

| 변수 | 기본값 | 켜면 |
| --- | --- | --- |
| `VITE_ENABLE_CAMPUS_THEME` | `false` | 캠퍼스 테마 색·배지·배너·배경 |
| `VITE_ENABLE_CAMPUS_TERRITORY` | `false` | 영토전 화면·지도·기여도·캠퍼스 메뉴 |
| `VITE_ENABLE_CAMPUS_SUPABASE` | `false` | 저장소를 Supabase 로 교체 (migration 적용 환경만) |

- 둘 다 꺼지면 **기존 앱과 완전히 동일**합니다. 라우트도 등록되지 않고
  `/campus` 로 직접 들어와도 404 없이 홈으로 갑니다.
- Preview 에서는 앞의 두 개만 `true` 로 두면 **mock 데이터**로 전부 확인할 수 있습니다.

## 8. 데이터와 개인정보

저장·전송하지 않는 것:

- 카메라 영상 · 사진 · 프레임
- 랜드마크 원본 · 자세 좌표 · 편차 수치
- `bad` 자세 상태 · 나쁜 자세 시간 · 건강 정보
- 자세 점수 (기여도 계산에 아예 쓰지 않습니다)

전송하는 것: 학교 · 시즌 · 타일 · 기여 종류 · 세션 id · 점수 · 익명 사용자 id.

- 회원가입을 요구하지 않습니다 (익명 사용자).
- 다른 사람의 기여 이력·소속은 조회할 수 없습니다 (RLS).
- 학교별 집계만 공개됩니다.
- `설정 → 모든 데이터 삭제` 가 학교 선택·기여 원장·익명 식별자까지 지웁니다.

## 9. Supabase

- migration 파일: `supabase/campus_territory_migration.sql`
- 테이블: `campus_schools` · `campus_seasons` · `campus_memberships` ·
  `campus_contributions` · `campus_tiles` · `campus_tile_events`
- 전 테이블 **RLS 활성화**. 쓰기 정책이 **아예 없고** security definer RPC 만 허용
  → 다른 학교 데이터나 남의 기여를 직접 수정할 수 없습니다.
- 원자적 RPC: `campus_record_contribution`(기여+멱등성+상한) ·
  `campus_capture_tile`(행 잠금 점령, 직접 호출 회수됨)
- Realtime publication: `campus_tiles`, `campus_tile_events`
- **Production Supabase 에는 실행하지 않았습니다.** 개발/스테이징 프로젝트에서만 적용하세요.

## 11. 열려 있는 결정 (상세: `docs/CAMPUS_DECISIONS_NEEDED.md`)

1. 친구 완주 +50 이 완료 +100 에 **더해지는지**(현재) 대체하는지
2. 하루 상한 600점과 기준 시각(로컬 vs Asia/Seoul)
3. 실제 시즌 길이·시작 시각
4. 학교 변경 제한을 AND(현재)로 둘지 OR 로 둘지 / 첫 선택도 잠글지
5. 기여 대상 타일을 사용자가 고르게 할지(현재) 자동 배정만 할지
6. 640px 미만 모바일 지원 여부 (앱 전역 사이드바 변경 필요)
7. 학교 색 프리셋·학교 이름 사용에 대한 디자인/법무 확인
8. 대학 인증 도입 여부
9. 시즌 보관 범위·기간
