# SCREEN SPEC

## 0. 공통 원칙

- 데스크톱 우선, 1280px 이상 최적화
- 아이보리 배경, 검정·딥 네이비 텍스트
- 핑크·노랑·파랑 파스텔 카드
- 캐릭터는 따뜻한 3D 렌더 이미지
- 세션 중 UI는 대시보드보다 단순하게
- 카메라 원본은 캘리브레이션에서만 제한적으로 표시
- 자세 점수 대신 회복·감지 가능 시간·출석·XP 사용
- 키보드 포커스와 감소된 모션 지원

## S-01 랜딩·대시보드 `/`

### 목적

서비스 목적을 이해하고 25분 세션을 시작합니다.

### 레이아웃

```text
[왼쪽 사이드바 232px]
[중앙 콘텐츠 minmax(0,1fr)]
[오른쪽 레일 300px]
```

### 왼쪽 사이드바

- UpRight Now 로고
- 사용자 닉네임·현재 성장 단계
- 홈
- 집중 세션
- 기록
- 성장
- 상점
- 친구 방
- 스트레칭
- 설정
- 하단 프라이버시 카드

### 중앙

1. 인사·오늘 목표
2. 메인 세션 카드
   - 현재 캐릭터
   - 상태 문구
   - 회복 콤보
   - 25분 집중 선택
   - 15분·50분 보조 선택
   - `지금 집중 시작`
3. 6단계 성장 진행도
4. 최근 세션

### 오른쪽

- 출석 캘린더
- 오늘의 기록
- 친구 방 CTA
- 빠른 메뉴

### 상태

| 상태 | 화면 |
|---|---|
| 첫 방문 | 닉네임·프로필·기준 등록 CTA |
| 기준 없음 | `자세 기준 등록하기` 우선 |
| 기록 없음 | 첫 세션 안내 |
| 재방문 | 캐릭터·25분 세션·최근 기록 |
| 카메라 오류 | 상단 배지와 복구 CTA |

### 수정 사항

시각 레퍼런스의 30분은 25분으로 바꿉니다. `점수` 표시는 사용하지 않습니다.

## S-02 닉네임 `/onboarding/name`

- 제목: `어떻게 불러드릴까요?`

## S-09 집중 세션 `/session/:sessionId`

### 레이아웃

상단:

- 과목·오늘 목표
- 남은 시간
- 감지 품질
- 친구 상태 · 친구 방일 때

중앙:

- 캐릭터 카드
- 자세 상태 문구
- 회복 콤보
- 모드별 괴물(북몽이·늘몽이·꼬몽이)
- 보스 체력

하단:

- 음소거
- 미니 위젯·PIP
- 스트레칭 예약
- 세션 종료

### 상태별 표현

| 상태 | 캐릭터 | 색·문구 |
|---|---|---|
| good | 편안한 기본 | 초록, `편안한 기준에 가까워요` |
| warning | 목·표정 변화 | 노랑, `자세가 조금 달라지고 있어요` |
| bad | 움츠림 | 핑크·코랄, `가볍게 돌아와 볼까요?` |
| away | 기다림 | 회색, `잠시 자리를 비웠어요` |
| unstable | 카메라 확인 | 회색·노랑, 복구 문구 |
| recover | 목을 펴는 중 | 파랑→초록 에너지 |
| success | 공격·축하 | 핑크·노랑 아케이드 연출 |

### 금지

- 상점·긴 통계·자유 채팅
- 카메라 대형 원본
- 자세 점수
- 의료 경고
- 긴 공격 애니메이션
