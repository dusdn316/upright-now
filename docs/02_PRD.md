# PRD — 제품 요구사항 문서

## 0. 문서 정보

| 항목 | 내용 |
|---|---|
| 프로젝트 | UpRight Now |
| 버전 | V1.0 |
| 상태 | 웹 프로토타입 구현 기준안 |
| 플랫폼 | 데스크톱 우선 웹앱 |
| 기본 세션 | 25분 집중 · 2분 리셋 |
| 핵심 기술 | MediaPipe Pose Landmarker · Supabase Realtime · 로컬 저장 |

## 1. 제품 목표

사용자가 노트북 공부 중 개인 기준에서 벗어난 자세 변화를 집중을 크게 방해받지 않고 알아차리고 회복하도록 돕습니다. 회복 행동을 6단계 캐릭터 성장, 마감 몬스터, 출석, 상점, 실제 2인 방과 연결합니다.

## 2. 우선순위

| 단계 | 의미 |
|---|---|
| P0 | 핵심 웹 프로토타입에 반드시 작동 |
| P1 | P0 안정 후 실제 구현 |
| P2 | 시안·후속 확장 |
| 제외 | 제품 원칙과 충돌하거나 현재 구현하지 않음 |

## 3. P0 기능

### FR-001 닉네임

- 첫 방문에서 최대 12자의 닉네임을 입력합니다.
- 입력하지 않으면 `익명의 기린`을 사용합니다.
- 현재 브라우저에만 저장합니다.
- 친구 방에는 닉네임만 표시합니다.
- 설정에서 변경할 수 있습니다.

### FR-002 학습 프로필

기본 프로필:

- 도서관
- 내 공간
- 팀플

각 프로필은 소리, 화면 효과, 위젯 크기, 스트레칭 추천, 자리 비움 처리를 포함합니다.

### FR-003 장소별 개인 기준

- 편안한 작업 자세를 5초 등록합니다.
- 카메라·조명·움직임 품질이 충분할 때만 저장합니다.
- 원본 영상과 프레임을 저장하지 않습니다.
- 기준 요약만 로컬 저장합니다.
- 기준 이름을 지정하고 재등록·삭제할 수 있습니다.

### FR-004 실시간 자세 상태

상태:

- `good`
- `warning`
- `bad`
- `away`
- `unstable`

초기 규칙:

- `bad` 5초 지속 → 회복 기회
- 회복 기회 30초
- `good` 5초 유지 → 회복 성공
- 회복 후 20초 냉각
- 같은 구간 보상 1회
- XP 추가 지급 회복은 세션당 최대 5회

수치는 의료 기준이 아닌 프로토타입 조정값입니다.

### FR-005 단계적 피드백

| 단계 | 피드백 |
|---|---|
| good | 캐릭터가 편안하게 공부 |
| warning | 목·표정 변화, 약한 노랑·핑크 신호 |
| bad | 캐릭터 움츠림, 코랄 테두리, 회복 기회 |
| bad 장기 지속 | 소리를 허용한 경우 짧은 알림 1회 |
| recovery | 목을 펴고 에너지 충전 |
| success | 1초 안에 공격·축하 |

### FR-006 집중 세션

- 기본 25분 집중·2분 리셋
- 15분·1분, 50분·5분 선택
- 3분 데모 제공
- 세션 시간은 사용자가 시작 버튼을 누른 시점부터 측정합니다.
- 자세로 집중 여부를 추론하지 않습니다.
- 과목·오늘 목표를 입력할 수 있습니다.

### FR-007 자리 비움

- 60초 미만: 타이머 유지, 자세 판정·보상만 정지
- 60초 이상: 계속·일시정지·종료 선택
- 친구 방: 공동 타이머 유지, 개인 상태만 자리 비움
- 벌점 없음

### FR-008 캐릭터 성장

6단계:

1. 뽀각 거북
2. 꿈틀 거북
3. 빼꼼 거부기린
4. 반듯 거부기린
5. 쭉쭉 기린
6. 우뚝 기린

장기 성장과 세션 중 자세 상태를 분리합니다.

### FR-009 회복 게임

| 현실 행동 | 게임 결과 |
|---|---|
| 세션 완주 | 기본 공격 |
| 자세 회복 | 특수 공격 |
| 스트레칭 완료 | 방어막 회복 |
| 목표 완료 자기보고 | 보너스 상자 |
| 두 사용자의 가까운 회복 | 기린 싱크 합동 공격 |
| 두 사용자 모두 완주 | 최종 필살기 |

### FR-010 개인 마감 몬스터

- 기본 보스는 모드별 괴물(북몽이·늘몽이·꼬몽이)입니다.
  (내부 상수명 `BOSS_NAME` — 사용자 화면 미노출)
- 3단계 체력 상태를 표시합니다.
- 세션 중 직접 조작을 요구하지 않습니다.
- 자세 회복과 완주가 자동으로 공격을 만듭니다.

### FR-011 스트레칭

- 6종의 검토된 일반 움직임을 제공합니다.
- 현재 모드에 따라 가중 랜덤으로 추천합니다.
- 직전 동작은 연속 추천하지 않습니다.
- 30~60초 모션·일시정지·다른 동작·건너뛰기를 제공합니다.
- 건너뛰기에 불이익이 없습니다.

### FR-012 결과와 기록

표시:

- 학습 세션 시간
- 자세 감지 가능 시간
- 자리 비움 시간
- 회복 성공 / 기회
- 가장 빠른 회복
- 최고 콤보
- 몬스터 피해량
- 획득 XP·잎사귀 포인트
- 캐릭터 성장
- 출석
- 목표 진행도 자기보고

표시하지 않음:

- 평균 자세 점수
- CVA 점수
- 정상·비정상 등급
- 통증 위험 점수

### FR-013 출석

- 10분 이상 진행 또는 정상 완료 시 출석
- 매일 처벌형 스트릭이 아니라 주간 목표 사용
- 휴식일 표시 가능

### FR-014 상점

- 대학 컬러 과잠
- 캠퍼스 백팩
- 구매·장착·해제
- 잎사귀 포인트 사용
- 장착 상태 로컬 저장
- 실제 학교 로고·마스코트 미사용

### FR-015 실제 2인 친구 방

- 회원가입 UI 없이 익명 사용자 생성
- 방 코드·링크로 입장
- 두 사람 모두 준비하면 방장 시작
- 각자의 자세는 각자 기기에서 분석
- 성공 이벤트만 공유
- 공동 보스·기린 싱크·공동 결과
- 연결 끊김 후 개인 세션 유지·재연결

### FR-016 로컬 데이터

저장:

- 닉네임
- 개인 기준 요약
- 학습 프로필
- 설정
- 세션 요약
- 성장·포인트·출석·장착 아이템

저장하지 않음:

- 영상·사진·프레임
- 얼굴 이미지
- 원본 랜드마크 시계열
- 통증·질환 정보

### FR-017 QA Lab

개발용 상태:

- good
- warning
- bad
- away
- unstable
- recovery success
- teammate recovery
- model failure
- storage failure
- PIP unsupported

운영 빌드에서는 환경 변수로 숨깁니다.

## 6. 제외 기능

- 자유 채팅

- 현금 상금

- 실시간 3D 모델
- Face Landmarker 기반 피로 판정
- 외부 음악 SDK

## 7. 프로토타입 성공 기준

- 첫 방문자가 10초 안에 서비스 목적을 이해합니다.
- 1분 안에 닉네임·프로필·캘리브레이션을 완료하고 세션을 시작할 수 있습니다.
- 회복 성공이 캐릭터와 공격으로 즉시 연결됩니다.
- 카메라 원본이 네트워크로 전송되지 않습니다.
- 2개 브라우저에서 공동 보스가 동기화됩니다.
- 카메라·3D·실시간 연결 실패에도 복구 경로가 있습니다.
- Vercel Production build가 성공합니다.
